## Cartoon characters (no images shipped)

We do **not** ship images for fictional cartoon characters (Peter Griffin, Stewie Griffin, Quagmire, Bender, Homer, etc.). These are copyrighted by their studios (FOX/Disney) and using them as repo assets — even small thumbnails — invites takedowns. The README uses **emoji placeholders** for cartoon-tier packs:

- 🍔 Peter Griffin
- 👶 Stewie Griffin
- 🤖 Bender
- 🟡 Homer Simpson
- 🌟 Patrick Star
- 🍌 SpongeBob

If a community contributor wants to ship cartoon-character art, they should source it from public-domain or fair-use-with-rationale sources and PR it into the separate [voice-forge-packs](https://github.com/humancto/voice-forge-packs) repo, not this main one.

## Takedown

If you are a rights holder and want a photo removed: open a GitHub issue. We'll pull within 48 hours, no questions asked.
