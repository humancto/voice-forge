01 install ~10 min, idempotent

three commands. that's the install.

one curl-pipe-bash for the binary. one heavy install for the cloning runtime (you can skip if you only want the OS-native fallback voice). then you bring an audio file.

STEP 1
binary on your $PATH. detects OS+arch, builds from source.
$ curl -fsSL voiceforge.sh/install | bash
STEP 2
downloads the GPT-SoVITS v2 stack (~1.7 GB). idempotent. macOS arm64 only for now.
$ voiceforge install-cloning
STEP 3
point at any clean local audio file ≥60s. one main + 5 aux refs, whisper-transcribed.
$ voiceforge clone peter ./peter.wav

prereqs the installer expects: git, cargo, ffmpeg. it tells you exactly which is missing if any are. inspect-first variant for the curl-wary in the README.

02 clone the proven recipe

the recipe that 100% whisper-verified on real Trump audio.

we tried XTTS, F5-TTS, GPT-SoVITS v2/v2Pro/v4. v2 with a 60s multi-aux-ref hit the sweet spot. the recipe:

source
≥60s clean single-speaker audio (you bring it)
trim
6 × 10s windows, loudnorm'd, mono 32kHz
transcribe
Whisper per chunk → prompt_text
backend
GPT-SoVITS v2 (1 main + 5 aux refs)
latency
~15s cold model load, ~3s synth thereafter
cache
sha256(text + voice + created_at)
verified output / Trump
3/3 lines @ 100% Whisper match
voiceforge clone
$ voiceforge clone trump ./speech_clean.wav ==> voiceforge clone trump ==> transcoding local source ==> duration check (≥60s) duration 60.00s ==> staging into trump.partial/ ==> whisper-transcribing 6 chunks ref_main: forces in ruins. their leaders... aux_1: command and control of the IRGC... aux_2: launch missiles and drones... ==> writing profile.toml ==> promoting trump.partial/ → trump/ ==> done voice: trump next: voiceforge say --voice trump --text "..."

a word on quality: stylized cartoon voices (Peter, Stewie, Quagmire) approach ~70% timbre fidelity zero-shot — the model averages distinctive cartoon timbres against its training distribution. real human voices (Trump, Obama, your colleague) get closer to 95%. fine-tuning is the path to 99%, on the roadmap.

04 pipeline under the hood

two layers. all local.

rust CLI for the dev-side surface (install, clone, say, run, doctor, daemon) and a python venv that hosts GPT-SoVITS v2. the synth is a long-lived NDJSON child — model loads once per process, warm for every call after that.

terminal event voiceforge process (build, test, git, agent) │ ▼ ┌─────────────────────┐ ┌──────────────────────────┐ │ apps/voiceforge-cli │ │ scripts/cloning_synth.py │ │ (Rust, async tokio) │ ───► │ (Python, GPT-SoVITS v2) │ │ │ NDJSON │ │ │ rule engine │ stdin │ lazy load │ │ engine facade │ stdout │ 1 main + 5 aux refs │ │ ~/.voiceforge/cache │ │ atomic write │ └─────────────────────┘ └──────────────────────────┘ │ │ │ embedded fallback │ cached .wav under │ (macOS say / espeak-ng) │ ~/.voiceforge/cache/ ▼ ▼ ┌─────────────────────────────────────────────────────────┐ │ rodio (CoreAudio / ALSA) │ └─────────────────────────────────────────────────────────┘ │ ▼ 🔊 speakers go brrrr

three engines, one façade. Engine::Embedded shells to say / espeak-ng for the default voice (no Python required). Engine::Server talks to a Flask server when VOICEFORGE_TTS_URL is set. Engine::Cloning spawns the long-lived NDJSON child. Engine::speak(text, voice) dispatches per-call based on whether the voice name matches a cloned profile.

04.5 quality tier pre-rendered packs

character voices. actually recognizable.

live cloning is fast and works for arbitrary text — but on stylized cartoon characters (Peter Griffin, Stewie, Quagmire) GPT-SoVITS v2 hits a quality ceiling. for terminal feedback (a fixed set of events) we render a pack of phrases once, on a beefy model — fish-speech S2 Pro — and ship the WAVs. runtime playback is sub-100ms.

one-time runtime, every event ┌──────────────────────────────────┐ ┌──────────────────────────┐ │ fish-speech S2 Pro │ ────► │ voiceforge say │ │ (research-license, OSS) │ │ --pack peter │ │ │ │ --event tests_passed │ │ 60s reference + prompt text │ │ │ │ → 13 × peter_event.wav │ │ → ~50ms WAV playback │ └──────────────────────────────────┘ └──────────────────────────┘ ~10 min/phrase on Mac CPU no synth, no model load ~5 sec/phrase on a real GPU

anyone can render their own packs. the full pipeline is documented in docs/PACK_RENDERING.md — clone any character voice, locally, in under an hour, no GPU required. CPU works; renting a GPU box for 10 minutes makes it a one-coffee operation.

community packs (peter, stewie, quagmire, trump, obama) ship as a separate index — educational/research/local-testing use only, takedown-friendly. the main repo stays clean.

05 privacy what stays on your machine

local-first. by design, not by promise.

voiceforge has zero accounts, zero cloud TTS, zero outbound calls beyond the one-time model download from HuggingFace. your reference audio, your cloned voices, your reaction text, the synth output — never leaves ~/.voiceforge/.

the codebase is open. the install script you can less first. the synth process you can strace. the model weights are on disk.
