# Example Fine-tuning Dataset

Use this format only when you are ready to fine-tune a voice.

```text
datasets/my_voice/
├── audio/
│   ├── 001.wav
│   ├── 002.wav
└── metadata.csv
```

Recommended quality:

- 20 to 30 minutes minimum
- 45 to 60 minutes preferred
- clean mic
- single speaker
- no music
- no background noise
- accurate transcripts
